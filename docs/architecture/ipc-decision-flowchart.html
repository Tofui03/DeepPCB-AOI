IPC-A-600 / 610 Defect Decision Logic

Deterministic multi-tier evaluation tree. Conductor failures (Open/Short) trigger immediate SCRAP, while parametric imperfections are bounded by Class 2/3 pixel tolerances and batch recurrence interlocks.

Override A

Zero-Tolerance Fatal Flaws

Conductor continuity breaches represent immediate catastrophic failure in bare-board inspection:

  • Open (Broken copper trace)
  • Short (Copper bridge between nets)
  • Max Area: 0 px (Unconditionally fatal)
  • Forced Verdict: SCRAP / CRITICAL

Override B

Parametric Area Tolerances

Localized defects are evaluated against Class 2 (General Industrial) and Class 3 (High Reliability) area thresholds:

  • Mousebite: 250 px (Cl. 2) / 120 px (Cl. 3)
  • Spur: 200 px (Cl. 2) / 100 px (Cl. 3)
  • Spurious Copper: 180 px / 80 px
  • Pin-hole: 160 px / 75 px

Override C

SMT Line Halt Interlock

Statistical process control detects repetitive systematic drift on the pick-and-place or etching line:

  • Tracked via isolated SQLite batch sessions
  • Trigger Threshold: N ≥ 3 occurrences
  • Forced: halt_production_line = True
  • Overrules any upstream VLM or operator pass
DeepPCB-AOI • Manufacturing Execution System (MES) Specification Standards: IPC-A-600K / IPC-A-610H
