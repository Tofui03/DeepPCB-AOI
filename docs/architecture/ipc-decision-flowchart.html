DeepPCB-AOI

Decision flow for one detected box

Open and Short are forced to SCRAP / CRITICAL. Other classes use a pixel-area limit: over the limit is REWORK / HIGH, and within the limit is PASS / LOW. The third occurrence of the same class in a batch sets halt_production_line.

Override A

Open and Short

These two classes always fail the area check and cannot be PASS:

  • Open (break in a trace)
  • Short (copper bridge between traces)
  • Max area: 0 px
  • Forced outcome: SCRAP / CRITICAL

Override B

Pixel-area limit

Other classes are compared with these caps. Over the limit, the rule outcome is REWORK / HIGH:

  • Mousebite: 250 px (Class 2) / 120 px (Class 3)
  • Spur: 200 px (Class 2) / 100 px (Class 3)
  • Spurious Copper: 180 px / 80 px
  • Pin-hole: 160 px / 75 px

Override C

Batch count

Each box increments a SQLite count for that batch and class. The code sets a flag:

  • Count is per (batch_id, defect_class)
  • Threshold: count ≥ 3
  • Sets halt_production_line = True
