# 能力库 (Capability Library)

> 跨项目复利资产：记录真实用过、有边界、可迁移的技术能力卡片。

| 能力块名称 | 技术名 | 在哪用过 | 边界与踩坑记要 |
| :--- | :--- | :--- | :--- |
| **毫秒级绝对差分与形态学去噪** | `cv2.absdiff` + `MORPH_OPEN` | DeepPCB-AOI (S1) | 极度依赖图像精准对齐；若图像有 1~2 像素抖动，边缘会严重亮起产生假警报。 |
| **ONNX Runtime 跨平台无显卡推理** | `onnxruntime` + `CPUExecutionProvider` | DeepPCB-AOI (S1) | 摆脱 PyTorch 沉重环境；在 CPU 上利用 AVX 向量指令集可稳定跑进 <15ms SLA。 |
| **NMS 几何非极大值抑制** | `apply_nms` (IoU 计算) | DeepPCB-AOI (S1) | 用于消除密集重叠的检测框；阈值设为 0.45，过高会有残留，过低会误杀真实相邻双缺陷。 |
| **0-Token 零开销极速旁路** | `Fast-Path Bypass` | DeepPCB-AOI (S1) | 工业良率 >90% 时的核心降本架构；无瑕疵直接放行，0 延迟、0 大模型 Token 消耗。 |
